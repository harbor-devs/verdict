# VERDICT

A private personal-finance app with a deterministic verdict engine and a witty friend-style personality. Default currency: PKR.

## Status

In development. This repository is the real rebuild.

An earlier prototype exists at https://verdict-finance-app.netlify.app. It used fictional data stored in the browser. This rebuild uses a real backend, real accounts and a real database.

## Planned stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: PostgreSQL
- Auth: session cookies
